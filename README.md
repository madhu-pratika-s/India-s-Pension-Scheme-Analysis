# 📊 Excel Data Analytics Mini Project: India Pension Ecosystem Analysis

## 📌 Overview
This project demonstrates an end-to-end data analytics workflow using **Microsoft Excel 365**. It focuses on transforming raw subscriber data into meaningful business insights through professional data cleaning, preprocessing, custom numerical grouping, Pivot Table analysis, and interactive dashboard development.

---

## 🎯 Project Objective
To analyze India’s diverse pension scheme datasets (**NPS, APY, EPS-95, UPS**), identify demographic, financial, and compliance patterns, and present actionable insights through an interactive Excel dashboard.

---

## ✨ Key Highlights
- **Raw Pension Data Collection and Exploration:** Inspected subscriber records covering demographics, schemes, fund managers, and financial metrics.
- **Data Cleaning and Preprocessing:** Standardized mixed text/date fields (`Date_of_Joining`, `Last_Transaction_Date`) using Excel's *Text to Columns* and filtering tools.
- **Handling Missing Values:** Identified and cleaned non-date strings (`"Not Provided"`) and missing entries to ensure accurate aggregations.
- **Custom Data Transformation:** Created calculated helper columns using formulas (e.g., `=INT(F2/100)*100`) for custom numerical interval grouping (PIN codes) alongside date grouping by month and year.
- **Multi-dimensional Pivot Table & Pivot Chart Analysis:** Built 10+ analytical views examining scheme participation, fund values, KYC/Aadhaar compliance, and tax benefit sections (`80CCD(1)`, `80CCD(1B)`, `80CCD(2)`).
- **KPI & Summary Metric Development:** Calculated total corpus under management, average expected monthly pensions, and subscriber counts.
- **Interactive Dashboard Creation:** Designed an executive dashboard equipped with dynamic **Slicers** for real-time filtering by state, sector, and gender.
- **Business Insights & Financial Data Visualization:** Translated complex multi-scheme data into clean, readable bar, column, and stacked charts.
